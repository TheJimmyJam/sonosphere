# Sonosphere Expansion Skin Pack 03 — Super Premium

A third pack of **50 super-premium Sonosphere skins**, designed to be meaningfully different from the first 100.

Each skin includes:

- `skin.json` — metadata, material concept, tags, support flags, visualizer defaults
- `theme.css` — CSS variables scoped to `:root[data-skin="skin-id"]`
- `preview.svg` — lightweight generated preview image

## Usage

```js
document.documentElement.dataset.skin = "obsidian-couture";
```

Load the selected skin's `theme.css`, or bundle all CSS files for instant switching.

## Design direction

This pack leans into premium product worlds: luxury materials, couture/fashion tech, resort environments, aerospace luxury, performance motorsport, audiophile gear, boutique synth hardware, architectural finishes, and executive interiors.
